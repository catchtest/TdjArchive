# 天地劫：神魔至尊傳 遊戲資料站

《**天地劫：神魔至尊傳**》遊戲資料與攻略整理，收錄流程攻略、劇情對話、角色、裝備、道具、絕學咒法、煉化配方、戰場與城鎮資訊，並提供線上存檔修改器。

瀏覽網站：**[天地劫：神魔至尊傳 遊戲資料站](https://catchtest.github.io/TdjArchive/)**

## 網站內容

- **流程與隱藏條件**：依幕數整理通關重點、角色加入、隱藏寶物、特殊事件、真結局與隱藏關卡的觸發條件。
- **人物誌**：角色能力、五魂、成長、可用裝備與絕學習得條件，搭配人物頭像與站姿查閱。
- **裝備與道具**：能力加成、特殊效果、適用角色、價格與取得來源，區分可取得及無法取得的物品。
- **絕學咒法**：招式屬性、消耗、威力、射程、作用範圍與附加狀態，並連結相關角色與物品。
- **戰場與城鎮**：可縮放、點選的格子戰場，查看地形、敵我配置、增援、隱藏寶物、勝敗條件與劇情對話；城鎮另收錄人物對話、商店與出口。
- **煉化譜**：按武器、防具、飾品與道具查詢配方，展開煉化樹追查原料及取得方式，並標示無法取得或無法煉化的項目。
- **狀態**：整理各種狀態的效果、相關技能與持續量說明。
- **圖片集**：人物頭像、站姿、行走與招式圖片，方便辨識角色及放大檢視像素細節。
- **存檔修改**：載入一般存檔（`.GSF`）或戰場存檔（`.GCF`），調整進度、角色能力、裝備、絕學、物品及戰場站位，再下載修改後的存檔。檔案僅在瀏覽器內處理，並可下載原始備份。

支援分類搜尋、表格排序與資料交叉查詢。點擊相關人物、物品、絕學或關卡，可查看對應資料。

資料依原版遊戲檔案與機制研究整理，以遊玩查詢、隱藏條件及祕密揭露為主。遊戲資料、美術及文字著作權屬原權利人。
