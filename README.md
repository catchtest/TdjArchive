依《天地劫：神魔至尊傳》原版資料整理遊玩流程、隱藏條件與遊戲機制。

[瀏覽《天地劫：神魔至尊傳》遊戲資料站](https://catchtest.github.io/TdjArchive/)

## 網站內容

- **典藏總覽**　介紹遊戲背景與發行資訊，並提供人物與戰場入口。
- **人物誌**　查閱角色加入條件、初始能力與五魂、升級成長、自帶與可用裝備、絕技習得條件及傷害倍率。
- **法寶錄**　收錄我方裝備、道具與敵方裝備，列出能力加成、使用效果、價格、取得來源與可裝備者。裝備的「取得時機」可比較不限結局與真結局路線的最早取得方式。
- **絕學譜**　依我方與敵方的絕技、咒法分類，查詢屬性、威力、消耗、施法距離、作用範圍、附加狀態及習得或使用對象。
- **戰場圖**　在可縮放的格子地圖查看開場分支、敵我配置、增援條件、地形耗點、隱藏寶物與事件觸發區，並查閱勝敗條件和劇情對話。城鎮地圖可點選人物、商店與出入口，查看對話分支、商品與場景去向。
- **流程攻略**　按遊戲進度串接戰場與城鎮，整理通關要點、角色加入、容易錯過的素材與支線，以及真結局和隱藏關卡的觸發條件。
- **煉化譜**　按成品或原料查找配方，展開煉化途徑追查原料來源，並標示無法取得或因配方重疊而無法煉出的項目。
- **狀態**　查閱各種狀態的效果、持續量與相關技能。
- **圖片集**　分為角色、普攻、絕技與咒法。點選角色可查看頭像、站立、行走、戰鬥圖與出場關卡。
- **存檔修改**　在瀏覽器內開啟一般存檔（`.GSF`）或戰場存檔（`.GCF`），調整遊戲進度、角色能力、裝備、絕技、金錢、背包或戰場站位，並下載修改檔與原始備份。

支援分類搜尋、表格排序與資料交叉查詢。點擊相關人物、物品、絕學或關卡，可查看對應資料。
