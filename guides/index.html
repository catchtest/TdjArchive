完美結局路線

從早期贈酒、同伴加入到修復神劍，依序保留必要材料。以下包含結局分歧；片尾後的「兩百塊帝國」另有回合與版本條件。

按故事進度檢查

  1. 第一次到太原城時，與客棧旁酒客反覆交談到他同意分酒，再調查旁邊的木箱取酒。再訪太原時，到雜貨鋪把酒交給不淨散人。
  2. 第八幕「殺陣」要等不淨散人現身，再由我方搶先擊倒朱慎。朱慎會在第二十回合敵方行動前撤退，必須趕在這之前完成。先拿右上藏寶室的天河朱砂再擊倒朱慎。
  3. 第十幕「懸天古徑」在夏侯儀離開前擊敗他；第十五幕「魔骸」在鬼魄屍王破防後四回合內擊倒，並於二十四回合內過關，讓夏侯儀加入並取得冥華紫晶。
  4. 保留煉化材料，尤其冥華紫晶、天河朱砂與兩儀玄石。第二十一幕「神兵」要爭取兩儀玄石的限時獎勵。
  5. 「突圍」後最後一次在開封整備時，到客棧與太虛金仙交談，備妥珍瓏凈玉與魂翔之玉，出城選天炎嶺。
  6. 在「焚炎劫火」取得左下樹旁的火凜冰實，保留作七色瓔珞的材料。
  7. 進入「天琰神煌」之前煉成並保留七色瓔珞；可在「古月」結束後的整備完成。接上尚英修劍的劇情，取得修好的九儀天尊劍。
  8. 在「無幻剎那」擊倒劍邪第一形態後，讓殷劍平裝備修好的九儀天尊劍，在劍邪回池後第十次回合開始的倒數事件之前，站上靈闕池前指定事件格，觸發劍邪犧牲的分歧。
  9. 繼續通過「天之顛地之涯」「千幻華舞」，在「冰嶽絕劍」擊倒蚩尤的心臟，完成後續結局。

最後分歧：擊倒劍邪後仍要觸發事件

劍邪第一次被擊倒後會移到池中央並成為無敵狀態，倒數從此後開始。實際期限是回池後第十次回合開始的倒數事件之前，須提前抵達事件格，不能等到第十次回合才移動。

殷劍平平時可使用其他武器，但進事件格前必須換回修好的九儀天尊劍。沒有修好神劍或錯過時限，會轉入封寒月犧牲的結局，無法繼續後三場戰鬥。

第三十幕 無幻剎那

辨認是否走上修劍劇情

「天琰神煌」有修劍與追擊鄲陰兩種開場。修劍路線由尚英帶路；不淨散人先以自動行動的友軍助戰，下一關才正式加入。

修劍路線的殷劍平在前十回合會持續失血，每回合減少三分之一體力，應安排回復。

第二十九幕 三界之門

隱藏同伴

夏侯儀加入

夏侯儀加入時帶來冥華紫晶，這是七色瓔珞的重要材料。只完成其中一場的條件並不足夠。

  1. 「懸天古徑」須在夏侯儀離開前打倒他，以陽之陣第二十四結束前為限，宜提前完成。
  2. 「魔骸」先觸發鬼魄屍王破防事件，之後四回合內將它擊倒。
  3. 整場「魔骸」亦須在二十四回合內結束。兩個時限同時達成，紫楓才會在戰後救活夏侯儀。

不淨散人加入

  1. 「亙古魂幡」後第一次到太原城，與客棧旁酒客反覆交談到他同意分酒，再調查旁邊的木箱取得陳年汾酒。
  2. 「幽谷寒琴」後再訪太原城，進雜貨鋪與不淨散人交談並贈酒。
  3. 第八幕「殺陣」要等不淨散人現身，再由我方搶先擊倒朱慎。須趕在第二十回合敵方行動前完成。
  4. 進入「天琰神煌」前完成七色瓔珞。符合條件時，他在該戰自動助戰，下一關加入隊伍。
第二十九幕 三界之門

天炎嶺與關鍵材料

離開開封前煉好兩件飾物

「突圍」後的開封城是出發前最後一次城鎮整備。先在客棧向太虛金仙詢問分支與隱藏路線，再與街上的道士交談，可取得材料提示。

完成「殺陣」的前置條件並與太虛金仙交談後，離城可選天炎嶺。選這條路時須持有珍瓏凈玉與魂翔之玉，才能進入有火凜冰實的「焚炎劫火」。

  1. 兩儀玄石 ＋ 紫蘊精玉 → 太初華晶
  2. 太初華晶 ＋ 天河朱砂 → 珍瓏凈玉
  3. 紫蘊精玉 ＋ 雲龍珠 → 魂翔之玉
第二十三幕 黃泉幽徑

神兵：兩儀玄石的限時獎勵

建議陽之陣第十之前關門，並在陰之陣第二十之前結束戰鬥。實際獎勵界線為第十一回合敵方行動前關門，且於第二十回合內過關。這是兩儀玄石的額外獎勵時限，並非一般過關的敗北期限。

讓封寒月前往左下大書櫃前的機關，同時安排其他人清敵與搜寶。此時取得的兩儀玄石可用於離開開封前煉成珍瓏凈玉，不能等到後期才補。

焚炎劫火：先拿火凜冰實再清場

火凜冰實在戰場左下樹旁，座標為（3, 26）。進入天炎嶺但未撿取材料，仍無法完成七色瓔珞。

首次全員損失三分之一體力是在第二十回合敵方行動前；第二十二回合起，每兩回合的我方行動前再次發生。第三十四回合我方行動前強制敗北，搜寶與清敵須同步推進。

火凜冰實作為道具使用會消失；要走完美路線，請留給煉化。

七色瓔珞煉化順序

進入「天琰神煌」前完成，並保留成品。材料用途互相重疊，先確認以下六步所需的份數。

六步完成七色瓔珞

  1. 冥華紫晶 ＋ 烏光玄鐵 → 魂剎玉
  2. 神烏金翎 ＋ 輝月魂石 → 流光鏡玉
  3. 火凜冰實 ＋ 翡翠碧沙 → 千稜幻玉
  4. 赤煉火銅 ＋ 流光鏡玉 → 赤霞珠
  5. 赤霞珠 ＋ 魂剎玉 → 血纓石髓
  6. 血纓石髓 ＋ 千稜幻玉 → 七色瓔珞

三個容易斷掉的材料來源

冥華紫晶隨夏侯儀加入取得；天河朱砂在「殺陣」右上藏寶室；火凜冰實只在天炎嶺分支「焚炎劫火」取得。這三項都要隨故事進度及時完成。

「神兵」有神烏金翎、輝月魂石、紫蘊精玉與翡翠碧沙等材料，別只顧關門而漏拿寶箱。烏光玄鐵與赤煉火銅可在城鎮購得。

第十幕 懸天古徑第十五幕 魔骸

冥華紫晶不要先拿去煉五尊神令

五尊神令與七色瓔珞的材料鏈都會用到冥華紫晶。在「神兵」若把這份材料用在夢想無雙的煉化路線，會失去完美結局所需的材料。先完成七色瓔珞的路線規劃，再決定其他煉化。

片尾後的兩百塊帝國

這是完美結局之後的額外隱藏關，需使用 1.3 版並另達成回合限制。

版本、回合與等待條件

  1. 先安裝 1.3 版更新。
  2. 第二十五幕「宿命」須在第十三回合或之後過關。特殊事件總表寫十二回合以上，但關卡頁寫超過陽之陣第十二；事件腳本也會排除第十二回合及以前過關，因此第十二回合仍太早。
  3. 第三十三幕「冰嶽絕劍」在三十五回合內結束，目標是蚩尤的心臟。
  4. 看完所有片尾，畫面落幕變暗後再等待約一至三分鐘。
隱藏關 兩百塊帝國

兩場戰鬥的目標與步調不同

「宿命」可以全滅敵人，或讓存活的我方成員抵達對岸安全區。要保留隱藏關資格，就不能急著離場。

「冰嶽絕劍」則要搶時間：先打通往心臟的路，集中攻擊心臟。蚩尤大頭並非過關目標，也不必為了清掉所有增援而拖延。
