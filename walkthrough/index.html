第四幕隱者

第五幕前襄陽城

  • 支線先和客棧裡提到樹下信物的丈夫交談，再與妻子交談兩次。
  • 進關前煉古印劍給殷劍平。有百分之百的會心率，之後可用來煉古劍‧龍皇。
    • 煉化辟邪玉佩 ＋ 翡翠碧沙 → 西方神徽
    • 煉化青鋼劍 ＋ 西方神徽 → 古印劍

    • 煉化靈鼩毛髮 ＋ 紫蘊精玉 → 獸魂石‧朱

第十四幕前天都城

  • 取材購買一份烏光玄鐵供七色瓔珞煉化。

    • 煉化霧幻雲袍 ＋ 鳳凰織錦 → 舞風霓裳

第十四幕螢火

第十五幕魔骸

  • 真結局先擊倒夏侯儀，在鬼魄屍王破禁後4回合內擊倒它，並在第24回合內過關。若第十幕也及時擊倒夏侯儀，他會在戰後入隊。
  • 必留夏侯儀自帶冥華紫晶，留給魂剎玉。煉五尊神令也會用掉它。

第二十一幕神兵

  • 真結局第11回合敵方行動前，讓封寒月到左下書櫃前關門。第20回合內清場可得兩儀玄石，留給太初華晶。
  • 取材撿雲龍珠。這關也能補撿紫蘊精玉、輝月魂石、神烏金翎與翡翠碧沙。
  • 劇情戰後取得朱刃血劍，可在下一幕破除三魄鬼眼。

第二十二幕突圍

  • 劇情讓封寒月裝備朱刃血劍，普通攻擊韓無砂，破除三魄鬼眼。
  • 支線想保留完整的朱刃血劍，就先換下它，改用其他攻擊直接擊倒韓無砂。朱刃血劍打破三魄鬼眼後會失去靈力。

第二十三幕前開封城

  • 真結局完成第八幕的條件後，到客棧與太虛金仙交談，開啟天炎嶺路線。街上的道士會提示七色瓔珞的材料。
  • 離城前用兩份紫蘊精玉煉出珍瓏凈玉和魂翔之玉，帶著成品選「往天炎嶺而去」。若之前沒買烏光玄鐵，這是最後一次機會。
    • 煉化紫蘊精玉 ＋ 兩儀玄石 → 太初華晶
    • 煉化太初華晶 ＋ 天河朱砂 → 珍瓏凈玉
    • 煉化紫蘊精玉 ＋ 雲龍珠 → 魂翔之玉

第二十三幕焚炎劫火

  • 天炎嶺分支清場前到左下樹旁撿火凜冰實，留給七色瓔珞。第34回合我方行動前必須過關。

第二十三幕黃泉幽徑

  • 扶桑古木分支可撿七岳神劍。走這條路會錯過焚炎劫火的火凜冰實。
